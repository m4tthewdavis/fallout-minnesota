# Project subagents

Ask Claude to use them by name, or let it pick by description.

| Agent | Use it for |
| --- | --- |
| `sim-rules-dev` | New mechanics as pure, tested rules in `src/sim/` |
| `screenshot-verifier` | Headless screenshots and log checks after visual changes |
| `bevy-reviewer` | Strict review of a diff for Bevy pitfalls and project invariants |
| `release-checker` | Package/CI/credits/README consistency before pushing |
| `audio-designer` | Synthesised sounds and sound rules |
| `perf-investigator` | Frame time, entity counts, LOD and settings costs |
| `visual-designer` | Art direction and implementation: palette/UI, lighting, models, textures, particles |
